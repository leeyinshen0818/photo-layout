# Photo Print Layout Manager

A lightweight Windows desktop app for preparing photos for A3 and A3+ printing.

## Features

- Standard A3 and A3+ / Super A3 support
- Custom photo size with `in`, `cm`, and `mm`
- Portrait and landscape orientation
- Fit Inside and Crop to Size modes
- Interactive crop adjustment
- Left Top and Center positioning
- Accurate 300 DPI rendering
- JPEG output with Save As
- Responsive UI for different screen resolutions and Windows scaling
- Standalone Windows executable
- Custom Windows app icon

## Workflow

Open Photo → Set Size → Fit or Crop → Preview → Output JPEG

## Supported Paper Sizes

- A3: 297 × 420 mm
- A3+ / Super A3: 13 × 19 in
